# 番茄钟

一个淡红与白色主题的番茄钟网页，支持设置工作与休息时间（精确到秒），并提供开始、暂停与重置控制。

## 功能

- 自定义工作时间与休息时间（精确到秒）
- 支持设置工作轮数后触发长休息
- 工作时间结束后自动切换至休息时间并开始计时
- 工作结束时中间卡片抖动提醒
- 任务管理：每轮开始前可选输入任务，完成后打钩或标记完成度
- 今日统计：完成轮数与专注时长分布图表
- 成就系统：累计专注与完成轮次解锁小成就
- 响应式布局，适配移动端

## 使用方式

1. 直接在浏览器打开 `index.html`。
2. 选择工作时间与休息时间。
3. 可选输入本轮任务内容，点击“开始”启动番茄钟。

如需本地启动静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。
